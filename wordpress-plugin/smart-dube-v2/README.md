# Smart Dube (???? ??) — WordPress Plugin

Complete Buy-Now-Pay-Later (BNPL), neighborhood credit ledger, receipt OCR scanner, and SMS reminder system for Ethiopian merchants and customers.

## ?? Installation

1. Upload the `smart-dube` folder to your `/wp-content/plugins/` directory, or upload `smart-dube.zip` via **WordPress Admin -> Plugins -> Add New -> Upload Plugin**.
2. Activate the plugin through the **Plugins** menu in WordPress.
3. Create a new page (e.g. titled "Smart Dube") and insert the shortcode:
   ```
   [smart_dube_app]
   ```
4. Click **Publish** — your entire Smart Dube system is live on WordPress!
